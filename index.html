zamu

Auto-rotating bulk SMS scheduler for Android — every SMS takes the next template in turn, T1 → T5 and back to T1.

Interactive prototype with the real rotation engine and 3,169 demo clients. Press Start sending to watch the carousel move one template per SMS, import your own CSV / XLSX, search a number in the Planner, or download the sent log. Sending is simulated in this prototype. State is saved, so a reload continues from the same SMS — the same resume rule the app uses after a crash or restart.
